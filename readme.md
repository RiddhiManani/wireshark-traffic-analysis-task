# Task 5: Capture and Analyze Network Traffic Using Wireshark

## Objective

Capture live network traffic using Wireshark, identify common network protocols, analyze packet details, and export the captured traffic as a packet capture file.

## Tool Used

* Wireshark

## Operating System

* Windows 11

## Procedure

1. Installed and launched Wireshark.
2. Selected the active network interface.
3. Started packet capture.
4. Generated network traffic by browsing websites and using ping commands.
5. Stopped packet capture after approximately one minute.
6. Applied protocol filters such as DNS, TCP, and TLS.
7. Analyzed packet details including source and destination IP addresses.
8. Exported the captured traffic as a `.pcapng` file.

## Protocols Identified

### DNS (Domain Name System)

Used to resolve domain names into IP addresses.

### TCP (Transmission Control Protocol)

Provides reliable communication between devices.

### TLS (Transport Layer Security)

Encrypts communication between clients and servers.

## Findings

* DNS traffic was observed during domain name resolution.
* TCP packets established communication sessions.
* TLS packets indicated encrypted web traffic.
* Packet details were successfully analyzed using Wireshark.

## Result

Successfully captured and analyzed network traffic using Wireshark and exported the packet capture file for further analysis.
